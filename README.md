# Parallel Computing Project

## About
This repository contains the project for the Parallel Computing class of the Computer Science course. The project is implemented in Java.

## How to Run
1. Clone the repository:
    ```sh
    git clone https://github.com/osLeonardo/parallel-computing.git
    ```

2. Navigate to the project directory:
    ```sh
    cd parallel-computing
    ```

3. Compile the Java files:
    ```sh
    javac -d bin src/*.java
    ```

4. Run the project:
    ```sh
    java -cp bin Main
    ```
